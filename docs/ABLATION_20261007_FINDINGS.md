# 小批量消融结论与 Badcase 复核

日期：2026-10-07。状态：**可作为开发诊断分享，不支持总体性能提升结论**。

完整表格、逐题预测链接、Wilson/配对 bootstrap 区间、DAG 节点表见 [完整报告](ABLATION_20261007_SMALL.md)；样本和预算见 [预登记](plans/2026-10-07-small-ablation.md)。

## 实验范围

MiMo-V2.6-Pro，同一 BM25/OCR 索引，6 题 x 5 组 = **30/30 条真实轨迹**。ChartQA、PDFVQA A/B 各 2 题，覆盖六个原始题型，各取 ID 字典序首题。全部来自既有开发诊断集，每组仅运行一次，失败、弃答与无效输出均计入分母。

按用户要求，本轮不考虑图像向量。保留多模态重排及角色原图阅读；在线 OCR 消融不删除预处理 OCR。记忆、Wiki、Skill 和外部 MCP 的质量不由本轮结果验证。旧模型成绩、旧 oracle 和历史工具探针不混入本轮分数。

## 答案结果

| 组 | ChartQA relaxed accuracy | PDF A accuracy | PDF B 集合 EM | PDF B 集合 F1 |
| --- | --- | --- | --- | --- |
| 固定工作流 | 0/2 | 0/2 | 1/2 | 0.8333 |
| 完整 Agent | 0/2 | 2/2 | 1/2 | 0.5000 |
| 关闭重排 | 1/2 | 0/2 | 0/2 | 0.5833 |
| 关闭在线 OCR | 1/2 | 0/2 | 0/2 | 0.5833 |
| 关闭角色原图 | 0/2 | 1/2 | 0/2 | 0.3333 |

完整 Agent 在两道 PDF A 题上得分较高，但 ChartQA 没有通过，PDF B F1 也低于固定流程。不能挑出 PDF A 的 100% 作为总体性能；2/2 的 Wilson 95% 区间约为 34.2%-100%。各任务只有两题，配对 bootstrap 区间即使不跨零，也不构成稳定性或显著性证据。

ChartQA human 题“Which country data analysed here?”五组均失败。它依赖给定目标图，本实验却是跨图诊断，不能将结果解释为官方 ChartQA 给图能力。不能根据这一个样本认定关闭重排或 OCR 更好。

## 阶段结果

| 组 | 收集金页 | 最后回答上下文金页覆盖完整 | DAG 全部必达目标通过 |
| --- | --- | --- | --- |
| 固定工作流 | 5/6，另 1 条观测不完整 | 4/6 | ChartQA 0/2；A 0/2；B 1/2 |
| 完整 Agent | 5/6 | 5/6 | ChartQA 0/2；A 2/2；B 1/2 |
| 关闭重排 | 5/6 | 5/6 | ChartQA 1/2；A 0/2；B 0/2 |
| 关闭在线 OCR | 6/6 | 6/6 | ChartQA 1/2；A 0/2；B 0/2 |
| 关闭角色原图 | 5/6 | 5/6 | ChartQA 0/2；A 1/2；B 0/2 |

DAG 为冻结的阶段代理：evidence -> context -> answer/citations。保留原始分数与依赖计分，未知和阻塞不给分但不混同失败。此处“覆盖完整”是金页 ID 覆盖，不是文本完整、可读性或语义支持判断。PDF 给页任务天然容易命中页面，不能据此宣称高开放检索召回。

最清楚的诊断信号是：关闭在线 OCR 组的 6/6 题都收集到金页并进入上下文，但只有 ChartQA 1 题通过最终任务指标。因此失分不能统一归咎于召回遗漏。所有组的 PDF B 上下文金标元素 ID 都覆盖 2/2，仍存在多选和格式失败。

## 工具与预算

实际自然工具调用 **83/86 正常返回**。三个错误为一次 `ocr_page/tool_failed` 和两次 `read_page/page_not_found`；正常返回不等于选择正确或新增有效证据。完整 Agent 的成功取证工具命中金页 5/6 题。

已经逐条核查：关闭在线 OCR 组没有 `ocr_page` 调用；关闭重排组没有 rerank 模型请求；关闭角色原图组的 Researcher/Answerer/Verifier 图像输入为零；固定流程没有工具节点调用。各组每条轨迹实际发送生成请求均不超过 18 次。

| --- | --- | --- | --- | --- |

保存轨迹共 **349 次已发送请求、1350065 个已上报 Token**；342 次请求有 total_tokens，7 次未知，预算拒绝 2 次不计已发送。实际最大输入 12764、最大输出 4565 Token，不能证明 1M 窗口收益。

运行曾在 13 条落盘后中断，代码/配置指纹一致后继续剩余 17 条，没有重跑已保存的失败。中断时未落盘请求的 usage 不可恢复，以上数字**不是完整账单上限**；未知 usage 不视为零。历史预处理和历史工具探针不计本轮新增成本。

## 验证与下一步

- 30 个 `(case_id, variant)` 无重复、无缺失；运行代码指纹在恢复及结束时一致。
- 逐条独立重算本批答案命中数、集合匹配、请求数和已知 Token 合计，与保存的 summary 一致；单独核对消融开关和请求上限。
- DAG 报告检查原始运行/预测指纹，并重新计算节点结果；不会将其他运行的 DAG 输出拼入本报告。
- 相关离线回归 131 项通过；测试通过只验证实现，不为模型质量背书。

下一轮优先只改变答案输出契约，保留本轮原分数，在相同题目上做配对回归；再针对否定问题的引用核验建立原图复核样本。扩大样本或重复种子应安排在协议问题修复后，并补独立未见题。当前不扩展图像向量实验。

本轮不能用于声称“多模态/Agentic 各组件均有效”，但已经提供可复现的小样本对照、阶段诊断和成本记录，能据此明确下一轮修复顺序。
