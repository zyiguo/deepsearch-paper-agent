## 三组配置

| 方法 | 预算提示 | 强制停止研究 | 默认业务行为 |
|---|---|---|---|
| `mainline` | 无新增 | 原有硬上限 | 不变 |
| `mainline-budget-visible` | Supervisor / Researcher 可见 | 无新增 | 仅显式评测启用 |
| `mainline-budget-bounded` | 与 visible 相同 | 下述规则 | 仅显式评测启用 |

控制器独立于模型、语料和评测标签。`ResearchWorkflow` 可注入 `budget_control`；
评测适配器从共享 runtime 提供剩余模型调用、检索调用、累计记账 token、时间和输出上限。
只有成功搜索返回的入选片段 ID 用于“新增片段”统计，不访问 gold、答案或语料内容。

预算指导提示仅加入规划角色，不改变 Verifier 指令，不允许因为资源不足降低证据支持标准。
visible 和 bounded 均提示只补原问题必要条件，不额外要求日期或精度。
因此原组与 visible 的差异包含预算字段和配套指导，不应归因于仅添加数字字段。

## 首版固定规则

任一条件触发后停止新增研究，并保持该状态直到本题结束：

- 剩余检索调用为 0。
- 剩余模型调用不超过 5，给起草、核验、可能的格式修复、调度和短答案转换预留资源。
- 剩余记账 token 不超过 5 个输出额度，或剩余时间不超过 30 秒。
- 连续两次搜索没有新增入选片段 ID。

Token 与时间阈值都是启发式，不保证最终提示词一定能装入或云端一定按时返回。
“没有新增片段”也不等于没有新信息，更不等于证据已经充分；该策略可能过早停止，需要实验验证。
控制器在规划调用前、工具派发前检查，防止规划本身消耗资源后再超出保留界限。

停止研究后：有证据且尚未核验时走原 Answerer -> Verifier；无证据则结束；
已核验但仍有未支持结论/缺口时保留 incomplete，不自动把结论标为支持。
核验通过的部分 claim 可以沿用现有短答案转换，这不是整题闭环已完整。
所有最终调用仍受公共硬预算限制，超限仍记失败，不暗中增加调用额度。

## 验证范围

- `725 passed, 2 skipped`，包括 13 项预算专项测试。
- 覆盖真实图停止、检索上限、规划后再检查、重复片段、无证据弃答、核验拒绝、
  Verifier 不接收预算、visible 不强制停止、未知/非有限计数拒绝。
- 本轮云端仅用原有两个 canary 清单各一题，每题三组，共六次尝试，失败不重试。
- 保持原 MiMo、BM25、k=5、24 次模型调用、8 次检索、256000 累计预算、8192 输出、
  131072 上下文、600 秒总时限与 300 秒 HTTP 配置；直连云端。
- 三组在同一代码身份运行，使用默认严格 `compare`，不需要跨版本豁免。
- 冻结实现 SHA256：`7e5d456da88485c55d422c4688d144abc10d404f0983cf9a0d24c9f688f7c827`。
- 预算字段是生成提示时的调用前快照；该次规划调用本身仍要消耗资源，工具派发前会再检查。
- MuSiQue canary 本身存在中间证据链缺口疑点，适合检查终止机制，不适合单独证明推理准确率提升。
- 后续正式实验应为两数据集各 10 题、三组共 60 次运行，另行报告 EM/F1、失败、弃答、
  核验状态、人工证据支持审查与用量。不以 Verifier 自评代替独立事实正确性评价。
