## 使用边界

成本点是内部整数单位，未知用量继续冻结，图像及推理估算不是实际金额上限。第三方 MCP 的费用尚未自动计量。指标计数器与直方图重启会重置，费用、审计和告警状态持久保存。告警通过 API 与日志输出，外部监控采集和通知仍需部署配置。工具未知结果的人工核对与费用核对分别审计，任何一方确认都不能替另一方证明完成。
