# 已确认缺口的增量核验（v5）

v5 是可选实验策略，复用 v4 的稳定候选编号与未知保留机制。`AGENT_EVIDENCE_POLICY_VERSION=v5` 配合显式启用证据控制使用，生产默认不变。

## 增量核验规则

独立核验器将一个候选的所有提交路径评为 unknown，且明确存在未支持的要求时，记录候选编号、缺失要求、已提交引文的内容/来源指纹、评审及证据快照指纹。重复或越界的评审、矛盾结论、通过结论不会成为可复用的未知缺口。多个未知路径的已支持要求取并集，其余才作为共同缺口。

生成器收到紧凑的缺口提示，不把“缺少证据”的说明当作支持性步骤。下一轮仍向生成器提供实际证据。若一个候选路径只重复已有引文，没有任何新的可定位引文，则暂缓该路径的语义核验，继续保留 unknown。新引文、新来源、来源内容变化、视觉信息变化或新候选都会重新进入核验；同一候选的新替代路径可以单独进入。引用编号变化本身不算新证据。

暂缓只复用未知，不复用通过结论，不构成硬剪枝。未提交路径不能被核验器选为已支持。问题、要求、指令、记忆、技能、客户端或工作流实例变化使缺口复用失效；新工作流恢复保守重审。缺口状态在检查点中保留，可用于归因，不能跨新实例直接恢复为可信结论。

**局限：**这里的“已确认缺口”指独立模型报告，仍可能错误。相同引文上的新推理可能纠正旧误判，当前机制会暂缓此类重试；它优先避免重复未知成本，不能保证零误暂缓。新的未被生成器引用的证据可能被漏用。因此必须同时检查答案质量、未知数量与成本，不能把候选未删除等同于召回率不下降。

## 输出长度与审计

核验提示要求每路径理由不超过 280 字符、问题和检索查询保持短句。新契约对理由严格保留前 280 字符；原始模型输出先记录，之后只对诊断理由做本地裁剪。verdict、supported_requirements、selected_candidate 等决策字段保持严格校验，不因裁剪变更。问题及查询数量沿用现有契约，文本简短通过提示引导，避免裁剪查询改变检索语义。

该裁剪能避免仅因理由过长再发修复调用，但不能追回已经生成的 Token，也不能防止整份响应被提供方截断。

新增事件：`candidates.gap_state` 保存缺口，`candidates.gap_review_deferred` 保存路径编号、缺口、原评审身份与暂缓原因。全部待评路径被暂缓时，`candidates.verification_skipped` 记录 `confirmed_gap_without_new_witness`；原证据、候选和路径继续留在轨迹。真实语义核验与本地未知判断通过 `semantic_review_performed` 区分。

## 对照协议

输出目录 `output/incremental-gaps-20261019`。在同一冻结源码内重新运行 v4 与 v5，复用原四道 Badcase/成功对照、MiMo v2.6 Pro、原语料和预算：每题 24 模型调用、8 次检索、256000 Token、600 秒，输出上限 8192，上下文 131072、top-k 5。每条件一次真实运行，不自动重试。

KABG 沿用错误金标隔离，仍统计其成本。真实用量缺失保持 null；成功、失败、未知分组保存。以本次同构建配对结果为主，不把上一次 v4 的随机运行当成本次基线。四题是开发案例，不能据此推断总体性能。无人类路径标签时误剪率仍为 null。

### 哪些机制实际触发

- KABG 的 v5 记录了缺失要求 `[1]`（县名桥接），始终保留原候选。前两轮分别独立核验，第三轮生成器没有再用缺证解释构造支持路径，提交空路径，跳过一次核验。核验 Token 从 17830 降至 10430。
- v5 的五条真实核验理由长度分别为 175、187、218、253、276 字符，均在 280 内；实际没有触发本地裁剪。超长理由本地裁剪不重试的行为由实际图的脚本响应测试验证，原始回复在测试轨迹中完整保留。
- v4 的 The North Star 核验产生 1108 字符理由，触发修复；v5 未发生此修复。该题核验 Token 从 12154 降至 7849。不过 v4 同题还发生一次 Researcher JSON 格式修复，属于随机生成差异，不能归为增量核验的确定收益。
- **已确认缺口、相同引文的暂缓分支实际触发 0 次。** KABG 后续提交了变化的引文，按保守规则重新核验；第三轮为空路径，由空路径守卫处理。因此本轮实测支持“短理由与缺口提示组合下成本下降”，不能独立证明相同引文复用带来了线上节省。该分支已通过定向测试，包括旧证据重复、新证据重开、来源变化、新替代路径及恢复失效。

后续验证应覆盖“同一引文上的推理纠正”和“新证据未被生成器引用”两类反例，并增加重复运行/更大验证集。当前保持 v5 显式开启，不因四题成本下降自动切换生产默认。
