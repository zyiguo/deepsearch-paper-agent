# 外部 Baseline 云端重验收 V2

运行开始：2026-10-07；补齐与审计完成：2026-10-08。方法：IRCoT-adapted / LogicRAG-adapted；模型：`mimo-v2.6-pro`。

## 结论

**结构化响应适配通过真实云端验证，已落盘错误记录通过审计；整体 baseline 稳定性仍未全部通过。**

- 4 次单题 canary 和 40 次正式 pilot 均已有结果。两个数据集各 10 个不同问题，两种方法使用相同题目；不是 40 个不同问题，也不是完整 1,000 题测试集。
- Pilot 正常执行从首轮 32/40 变为 36/40；JSON 协议失败从 5 次变为 0 次。所有失败仍计入评分分母。
- LogicRAG 两个数据集均为 10/10 正常返回；原先 5 个协议失败题全部产生了答案，其中仅 1 个严格 EM 命中，不能把执行恢复等同于答对。
- IRCoT 的 2Wiki 为 10/10 正常返回；MuSiQue 保留 4 次失败：3 次输出截断、1 次服务端内容过滤。
- 四组的 EM 均与首轮相同。LogicRAG 的 F1 有变化，但 n=10、默认云端采样与开发集反复检查的条件，不支持显著性或方法优劣结论。
- MuSiQue / IRCoT 在保存第 9 题后发生运行中断。确认旧进程已停止后，以相同身份仅补最后一题；中断前可能已发出的未落盘请求及费用未知，不能宣称完整账单已核清。

首轮结果见 [首轮云端验收报告](MULTIHOP_CLOUD_ACCEPTANCE_20261007.md)，代码修复见 [结构化响应与错误记录修复](MULTIHOP_RESPONSE_FIX_20261007.md)。没有覆盖首轮结果或更改金标准。

## 修复验证与 Badcase

### 结构化协议

正式 pilot 的 LogicRAG 共解析 38 次结构化响应：31 次 fenced JSON、3 次纯 JSON、4 次说明文字加 fenced JSON，均通过解析。未增加用于修复格式的模型调用。

首轮的 5 个协议失败题在本轮均正常完成：

| 题目 ID | V2 EM | V2 F1 | 可观察结果 |
|---|---:|---:|---|
| `3cec35b4091011ebbdadac1f6bf848b6` | 1 | 1.0000 | 2Wiki：依赖图说明包装被接受，补检后正确回答影片先后 |
| `2hop__20256_74481` | 0 | 0.6667 | 返回角色名及附加说明，严格答案不匹配，标注支持召回为 0 |
| `2hop__263728_705527` | 0 | 0.0000 | 累计支持召回为 1，但最终称证据未说明答案；需进一步检查摘要/证据利用 |
| `3hop1__593288_720914_27537` | 0 | 0.4000 | 返回前往罗马参加教宗选举的长句，未满足严格短答案匹配 |
| `3hop1__90327_78276_68042` | 0 | 0.0000 | 返回错误时间，且标注支持召回为 0 |

不能将上述 5 个变化全部归因于包装解析：本轮其中一题的依赖图本身是标准 fenced JSON，模型输出也存在采样变化。可确认的是新协议在真实响应中接受了 4 次说明包装，并且本批不再发生 JSON 协议失败。

2Wiki / LogicRAG 的 EM 未变还有一个具体原因：上述影片题从失败变为正确，但 `2330faf1097511ebbdb0ac1f6bf848b6` 本轮返回 `Sudden Fear (1952)`，多带年份导致严格 EM 从 1 变为 0。报告保留这一回退，不事后剥离年份来提高分数。

### 中断恢复说明

2026-10-08 检查时，旧执行会话不可用，操作系统进程清单确认已无评测进程。MuSiQue / IRCoT 有 9 条已保存结果及遗留锁，最后缺少 `3hop1__9285_5188_86687`。

保留并归档旧锁为 `run.lock.interrupted-20261008`，保存 `recovery-20261008.json`；核对代码、模型和配置身份后执行同配置 `--resume`，只补缺失题，不使用 `--retry-errors`。最后一题正常返回；恢复前 9 条记录的字节前缀哈希一致，`run.json` 哈希不变。

**未知项：** 旧进程在最后一次逐题落盘后可能已发出请求，其调用数、用量和结果无法确定。当前运行器按题持久化，不能从文件恢复尚未落盘的调用事件。因此上述成本和耗时仅覆盖已保存尝试，不能视为完整账单或严格等实际消耗对照；报告没有把未知费用记为 0，也没有将物理执行次数断言为恰好 44 次。
