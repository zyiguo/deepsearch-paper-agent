# 扩大数据与重复对照：缺口复用安全性及成本稳定性

GitHub 可直接读取的脱敏统计、配对明细和审计标签位于 [公开结果包](../eval/results/gap-repeats-20261019/README.md)。下文 `output/` 路径指本地保留的完整冻结实验，不随发布上传。

## 冻结协议

本轮复用已有 MuSiQue、2Wiki 的 200 题池，从中固定选择 20 题：每数据集 10 题，保留原四道 canary，其余以 `SHA256("gap-repeats-20261019:" + question_id)` 排序选取。扩充题不依据本轮结果选择，也不在运行中替换。每题 v4/v5 各独立重复三次，共 120 次真实预测，60 个按题配对观测。

生产源码沿用上轮指纹 `ec5cb218c70c2ffe2970c263f5574be4fcd9a02b0ce1a3022cf364f1d510e407`，本轮只增加评测与审计工具，不调整模型提示或策略。保留原模型 MiMo v2.6 Pro、原 sampled_pool 语料、BM25、top-k 5，以及每题 24 次模型调用、8 次搜索、256000 Token、600 秒、8192 输出上限和 131072 上下文。四个并发进程，任务顺序在运行前随机冻结。供应商未提供本实验可控随机种子，重复是独立随机运行，不是同随机数配对。

每次重复单独目录。出错尝试保留且不自动重试。只有未完成题目允许在身份匹配时恢复。输出位于 `output/gap-repeats-20261019`。

## 指标与证据边界

- 自然触发：报告 v5 路径暂缓次数、含暂缓的运行数、含暂缓的不同题数；分母分别列出，路径观察不能当作独立题目。
- 质量：KABG 继续隔离错误金标，正常题共 19×3=57 个有效配对观测。分别报告原 canary 与扩充 16 题。执行成功、最终正确与未知分开。
- 成本：包括所有出错尝试，以实际供应商 Token 为准，缺失用量保持 null。统计每轮总成本、配对成本胜率，按题把三个重复整体重采样，进行 10000 次确定性 bootstrap。缺少完整用量的题簇不进入成本区间，单独列数，不补零。
- 误暂缓：基线正确/v5 错误且发生暂缓只是风险信号。对自然暂缓路径，额外进行不展示旧判断和金标的模型证据复核，以及清空缺口状态后的真实核验器重放。额外审计费用与主对照预算分开记录。模型复核不是人工真值，真实误暂缓率没有独立标签时仍为 null。
- 独立审计检查支持引文确实存在，并区分“候选答案可被当前证据支持”和“提交路径足以证明全部要求”。重放保留全部候选和原证据，重新计算引用完整性，不再次检索或生成候选。

## 单独的安全反例

`synthetic-safety-counterexample.json` 是构造性离线反例，不计入 120 次自然评测：证据为 “Alice was born in Paris.”，候选答案为 Paris。旧路径错误地声称 Alice 曾到巴黎旅行，独立评审标为未知；新路径将主张修正为证据直接陈述的出生关系，答案与引文均不变。

当前缺口复用指纹不包含主张文本，因此把修正后的正确路径也暂缓。实际生产核心函数已复现该行为。这证明规则**可能误暂缓正确推理修正**，即使它没有删除候选、也没有产生错误的肯定答案。反例不提供自然数据上的发生率；自然触发少或最终正确率持平，都不能抵消这项安全缺陷。

本轮保持代码冻结完成实验，不能中途修复再把不同实现的结果合并。该缺陷的修复应在下一独立版本中至少对主张变化重新核验，并再次验证成本与质量。

## 120 次真实预测结果

20 题×3 次×2 版本全部完成，60 个任务进程全部正常退出。预测层面 v4 成功执行 58/60，v5 为 59/60；三次失败均为供应商 `output_truncated`（HTTP 200，finish_reason=length），不重试，失败消耗计入成本。总计 936 次调用、3,451,810 Token，缺失用量为 0。

| 重复轮次 | v4 Token | v5 Token | v5 成本变化 |
|---|---:|---:|---:|
| 第 1 轮 | 538,795 | 660,748 | +22.63% |
| 第 2 轮 | 601,025 | 582,234 | −3.13% |
| 第 3 轮 | 543,478 | 525,530 | −3.30% |
| 合计 | 1,683,298 | 1,768,512 | **+5.06%** |

按题聚类 bootstrap 的“成本下降比例”95% 区间为 **[−18.78%, +8.29%]**，跨零。60 个配对中仅 27 个（45%）省 Token；20 题按三轮平均仅 8 题（40%）省 Token；配对 Token 差中位数为 +471。**未验证稳定降本，上轮四题一次运行的 −9.37% 未在本轮复现。**

扩充 16 题单独看，三轮成本变化分别 +21.94%、−5.60%、+3.30%，成本下降区间 [−22.67%, +9.41%]，同样不支持稳定降本。区间只描述本次选定开发题，不能推广到完整数据集。

质量排除错误金标 KABG 后：v4 为 22/57（38.60%），v5 为 25/57（43.86%），变化 +5.26 个百分点，按题聚类区间 [−7.02, +17.54] 个百分点。4 个正确→错误、7 个错误→正确；4 个退化观测都没有触发暂缓，不能据此判断暂缓无害。扩充题为 17/48→18/48；原 canary 有效观测为 5/9→7/9。正确率变化尚无稳定提升证据。

成功/失败/未知按最终结果单独存档：v4 为 22/5/33，v5 为 25/6/29。执行成功不等于答案正确；错误金标样本仅隔离质量统计，成本全部保留。

## 缺口复用确实触发，但未形成整体节省

自然轨迹中有 **9 条暂缓路径，涉及 7/60 次 v5 运行和 6/20 道不同题**；这些不是 9 个独立样本。每条均找到对应旧评审，用原证据、候选和缺口状态重放实际规则，9/9 与原决策逐字段一致。所有暂缓记录保持 `unknown`、`pruned=false`，未通过该决策删除候选。6/9 条路径的主张列表相对旧评审已变化；变化可能只是措辞，不能自动等同于新增有效证明。

只有 **3 次整次核验因 `confirmed_gap_without_new_witness` 跳过**。其余暂缓只过滤部分路径，仍可能调用核验器处理其他候选。因此路径暂缓次数不能直接乘以平均调用成本估计净收益。

| 角色 | v4 调用 / Token | v5 调用 / Token | Token 差 |
|---|---:|---:|---:|
| Supervisor | 61 / 101,807 | 62 / 103,910 | +2,103 |
| Researcher | 217 / 516,502 | 217 / 512,789 | −3,713 |
| Answerer | 89 / 614,247 | 93 / 664,273 | +50,026 |
| Verifier | 64 / 443,685 | 76 / 478,570 | +34,885 |
| Projection | 26 / 7,057 | 31 / 8,970 | +1,913 |

核验单次平均成本约 6,933→6,297 Token，但调用数 64→76，最终核验总成本反而增加；回答生成也增加了 50,026 Token。这是观测到的成本构成，不能把随机运行之间的全部差异归因于缺口规则。

单个波动案例：`2hop__235471_565925` 第 1 轮触发两条暂缓，成本仍从 24,281 增至 64,984；`3hop2__89854_38738_76291` 第 3 轮 v4 输出截断早停，v5 继续运行，两者成本为 21,863 与 81,701。因此保留失败成本的主指标反映实际端到端消耗，并不等于等工作量下的核验效率。不得事后删掉失败或高成本样本来制造节省。

## 自然暂缓路径审计

主实验结束后才启动独立审计，避免影响主实验并发负载。每条路径分别做一次不含金标、旧结论和版本标识的同模型证据判断，再用原候选和原证据、清空缺口状态，调用实际图核验器。重放不检索、不重新生成候选；不同路径可能来自同一次运行，不是独立真值样本。

| 暂缓案例 | 路径数 | 额外盲审 | 原核验器重放 |
|---|---:|---|---|
| Dragon Dreams 表演者出生地的城堡 | 1 | 证据不足 | unknown |
| Philippe 的祖母 | 1 | 引文不精确，判断无效 | unknown |
| Three Waltzes 作曲家出生地 | 2 | 1 次不足、1 次引文无效 | 均 unknown |
| Timor-Leste 总统 | 1 | 证据不足 | unknown |
| Navy Nurse / The Face in the Fog 导演年龄 | 2 | 均不足 | 均 unknown |
| Moby Grape / Sundazed Records | 2 | 均不足 | 1 条 supported、1 次输出无效 |

盲审 9 次中 7 次有效，0 次认定完整候选或路径充分；另 2 次返回的引用不能与授权原文精确匹配，保留原输出，判为无效而非安全。核验器重放共 11 次调用（含运行器自身允许的结构修复），8 次有效评审、1 次输出无效。0 次选中被暂缓候选，**但 1 条被暂缓路径改判 supported**。

具体分歧位于 `blinded-audit/0006.json`：原问题问表演者“属于哪个唱片公司”，数据金标是 Columbia Records；工作流拆出的要求又允许“released records under”。引文写明 Moby Grape 合辑由 Sundazed Records 发行。盲审坚持“发行方不等于艺人所属公司”，判证据不足；图核验器重放同时把 Columbia、Sundazed、Reprise 三个候选标为 supported，最终没有选中任何一个。这里存在问题解释和核验尺度分歧，不能把 supported 路径自动标成人工确认的正确答案，也不能把没有最终选中解释成暂缓一定安全。

本轮真实误暂缓率仍为 **null**，人工标签数为 0。“7 份有效盲审均未判充分”不是 0% 真实误暂缓率。构造反例已证明当前规则存在压住正确推理修正的可能；自然审计还显示重复核验结论可能变化，因此旧的 unknown 不应被当作不可推翻的事实。

审计额外消耗：盲审 60,162 Token，图核验器重放 79,392 Token，合计 **139,554 Token / 20 次调用**，全部用量已知。这些不计入主实验 v4/v5 成本表，也不计入降本幅度。包含审计的本轮远程总消耗为 3,591,364 Token / 956 次调用。

## 交付、验证与后续决策

本轮结论是：机制自然触发已验证；稳定降本未验证；正确候选免受误暂缓的安全性未满足。**保留 v5 为实验选项，不提升为默认生产策略。** 本轮没有修改生产源码，也没有因审计结果重跑或替换主实验样本。

下一独立版本应先修正安全边界，再考虑效率：主张、关系方向或路径结构变化应重新核验；相同证据下的旧 unknown 应是可失效的暂存结果；证据没有增量且推理没有实质变化时，应阻止重复生成循环，而不只是过滤核验路径。上述建议尚未在本轮实施或验证。修正后应继续固定这 20 题、三次重复和预算，并增加能覆盖主张修正的确定性测试。

本轮新增统计与审计工具测试 **6 passed**；另有先前本轮阶段测试记录。上一轮生产完整测试的 957 passed / 14 skipped 只作为同源码身份的历史证据，本轮未重跑全套。最终校验覆盖生产身份、历史文件哈希、原始语料清单、10 个分片、60 个运行配置、120 份首次尝试、统一模型/检索/预算、9 条决策重放、审计源哈希和无遗留运行锁。验证细节见 `validation-final.json`；交付文件校验和见 `delivery-manifest.json`。

主要文件位于 `output/gap-repeats-20261019/`：

- `plan.json`：预先冻结的样本、预算、作业顺序与身份。
- `summary.json`、`paired.json`、`per-attempt.json`：整体、配对和逐次结果。
- `success.jsonl`、`failure.jsonl`、`unknown.jsonl`：结果分组。
- `deferred-review.jsonl`、`rule-replay.json`：自然触发待审核数据与规则重放。
- `blinded-audit/`、`audit-validation-diagnostics.json`：原始审计输入/输出、无效原因与独立费用。
- `synthetic-safety-counterexample.json`：实际规则误暂缓正确主张修正的离线反例。
- `cost-breakdown.json`：各角色成本和整次核验跳过原因。

复现入口为 `scripts/evaluate_gap_repeats.py`（prepare / run / finalize）、`scripts/audit_deferred_gap_paths.py`、`scripts/probe_gap_deferral_safety.py`。prepare 和审计输出要求新目录；既有实验不可覆盖，run 只恢复未完成题目，不重试失败。Windows 下设置 `PYTHONPATH=src`、`PYTHONUTF8=1` 后使用项目虚拟环境。任何新的评测必须使用新目录保存，不能对本轮完整目录再次运行 finalize。
