# 动态研究技能

技能是本机用户维护的研究方法指引，不是知识库证据，也不是可执行插件。默认目录为项目根目录下的 `skills/`；可用进程环境变量 `SKILLS_DIR` 指定其他可信本地目录。不会读取 Codex 全局技能，也不会下载或安装远程技能。

## 使用

会话输入区的“选项 → 研究技能”提供自动按需加载、关闭、指定技能。真实模型的 DeepSearch 默认自动选择；基础 QA/演示模式只支持显式指定，不额外调用模型选择技能。每轮最多加载 3 个，回答下方显示本轮实际加载的名称。

新建 `skills/my-review/SKILL.md`：

```markdown
---
name: my-review
description: 在比较论文实验设计时使用，核对数据划分与对照条件。
---

# 实验设计核对

- 分别提取训练集、验证集、测试集的划分方法。
- 比较基线与实验是否采用相同评测条件。
- 区分未报告信息与已证实的缺陷，逐条引用文献原页。
```

名称必须与目录相同，使用小写字母、数字和连字符；描述最长 320 字符。YAML 由安全解析器读取。更新、新增、删除文件后，下一次提问自动重新发现；界面可点刷新更新目录，无需重启。已加载的正文固定在当前请求中；发现后、首次加载前发生变更则跳过，下一轮再读取。

内置 `paper-comparison`、`chart-reading`、`method-review`。只有用户明确维护的可信技能应放入目录：提示词规则并不构成恶意文本的安全沙箱。

## 装载流程

1. 每次提问创建独立技能会话，扫描直接子目录的 `SKILL.md`，仅读取 YAML 名称和描述。
2. Supervisor 看到目录，在原有调度 JSON 的 `skill_ids` 中选择技能，不新增模型调用。
3. 加载器验证路径、文件版本和预算后才读取正文，供后续规划、检索词生成和回答参考。
4. Verifier 不接收技能正文，仍独立检查结论和引用；技能不能扩大文献范围、创建证据或绕过校验。
5. 返回并保存 `skills_used`（名称与正文 SHA-256）；启用本地轨迹时记录 `skills.loaded`。

关闭技能或没有目录时，原有问答保持可用。自动选择不存在或过长的技能会被跳过；手动指定不可用技能返回 422，流式接口也先校验再开始回答。

## 边界

- 单文件最多 32 KiB，YAML 头最多 4 KiB；最多扫描 128 个候选，目录最多 24 个、约 1200 Token。
- 正文总预算为 1600 Token 与可用上下文四分之一两者的较小值，计入证据预算；不截断技能正文，超额则拒绝装载。
- 文件路径必须留在配置目录内，拒绝越界软链接；接口只读，不提供上传或编辑技能的能力。
- 本版仅加载 `SKILL.md`，不执行 `scripts/`，不加载相对引用附件、不启用 shell、网络或插件工具。技能文本只影响研究方法，不增加系统权限。
- 指定技能仅作用于当前请求，不自动继承上一轮技能；目录自动选择会在每次提问重新执行。界面模式是当前页面设置，刷新回到默认。

## API

`GET /api/skills` 返回 `skills`、`warnings`、`max_active` 和 `automatic`。

`POST /api/ask`、`POST /api/sessions/{id}/turns`、`POST /api/sessions/{id}/turns/stream` 均支持：

```json
{"question":"比较论文的实验设计", "skill_ids":["paper-comparison", "method-review"]}
```

省略 `skill_ids` 或传 `null` 表示自动；传 `[]` 关闭。文献范围、图片附件和技能参数互相独立。`skills_used` 只是方法使用记录，不能作为引用来源。
