# ADR-0002：使用 PostgreSQL + pgvector 统一数据层

## 状态

Accepted

## 背景

系统需要管理论文、集合、标签、页面、Chunk、会话、任务、证据和向量，并需要事务、过滤和关联查询。

## 决策

使用 PostgreSQL 作为事实数据库，使用 pgvector 保存 dense embedding。首版不引入独立向量数据库或 Elasticsearch。

## 后果

- 优点：关系数据与向量共享事务和过滤能力，备份与运维简单。
- 缺点：极大规模向量检索能力不如专用集群。
- 替代方案：独立向量数据库会增加双写一致性与备份复杂度，不适合 500 至 3,000 篇个人文献规模。
