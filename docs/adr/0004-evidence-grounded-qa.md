# ADR-0004：采用结构化证据约束问答

## 状态

Accepted。实现范围说明（2026-09-12）：已落地论文、页码、原文片段与编号引用校验；**未实现**证据立场分类（支持/反对/限制）与中文机器翻译辅助层。

## 背景

论文问答必须让用户检查结论来源。只生成带文献名称的自然语言引用无法验证具体页码和原文，也容易产生虚假引用。

## 决策

回答保存为结构化 claim 与 evidence 对象。每条主要结论关联论文、页码和原文片段；翻译只作辅助（待实现）。默认严格使用本地文献库，扩展知识必须明确标记（当前严格模式：无依据则拒答或明确不足）。

## 后果

- 优点：引用可审计，可计算覆盖率，并能为后续评测和报告生成复用。
- 缺点：回答生成后还需要引用验证；证据不足时答案可能更保守。
- 替代方案：自由文本引用实现更快，但无法可靠检测引用缺失或伪造。
