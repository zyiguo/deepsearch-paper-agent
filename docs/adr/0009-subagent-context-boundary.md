# ADR-0009：独立子 Agent 上下文与结构化交接

状态：Accepted。

背景：Researcher 子图已有独立工具消息，但主流程将完整对话历史和已有证据传入子图；Supervisor 也在调度时读取大量证据正文。随着工具结果增长，应明确最小交接协议，避免把局部执行过程作为全局决策上下文。

决定：使用 SubagentTask 传递自包含目标、约束和缺口；子图每次从空消息/观察起步，不自动继承主流程历史与记忆。结束工具规划时在原有结构化输出中附带候选结论和证据 ID，经应用校验构造 SubagentResult。Supervisor 只接收有总预算的紧凑结果，Answerer/Verifier 继续读取可信原文。

备选：直接转发全部轨迹会扩大提示词并引入无关工具内容；额外调用独立摘要模型增加延迟、费用和失败点。因此将结果摘要合并到现有结束动作，保留旧输出兼容。

取舍：主 Agent 缺少某些原始细节，但可以要求继续研究；子任务需要主 Agent 消解指代。结构化结论仍可能错误，因此不赋予其核验通过状态。保留共享工具预算与授权范围，避免通过重新分派重置成本或扩大访问权限。当前为上下文隔离，不引入并行执行、独立进程或多副本运行。

恢复边界：主图检查点可保存结构化结果和可信证据，子图原始观察不进入主图。旧检查点缺少新增字段时通过默认值兼容。子图中断前未完成的局部工具循环仍按原有恢复策略处理，不宣称获得了完整子图断点恢复。

实现显式使用 `checkpointer=False`，其禁用继承的含义见 [LangGraph 官方 compile 文档](https://reference.langchain.com/python/langgraph/graph/state/StateGraph/compile)。子图调用使用独立 Runnable 配置，避免继承主图的同步写入策略与运行时设置；复制其他 ContextVars 以保留请求取消信号。本地恢复回归覆盖“研究子任务完成后、主图下一次调度前中断”的路径。
