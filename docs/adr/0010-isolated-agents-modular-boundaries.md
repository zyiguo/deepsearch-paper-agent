# ADR-0010：独立父子 Agent 主线与模块依赖边界

状态：Accepted（2026-10-18）。补充 ADR-0006/0008/0009；旧快速 QA 与查询规划不再是生产切换项。

背景：问答、引用、文献、Wiki、工具及存储共用数据类型，却从业务服务互相导入；API 同时管理资源、索引和会话线程；通用轨迹库寄居训练包。继续叠加功能会扩大循环依赖、上线加载范围及错误归因的不确定性。

决定：采用模块化单体，保持单 API 进程和原 HTTP/前端契约。代码按 core/application/agents/knowledge/workspace/adapters/web 组织。共享契约为标准库类型，LangGraph 位于图运行实现；工具服务由适配器包装。索引服务独占锁、写保护与快照发布；应用用例拥有会话运行与资源生命周期。

生产真实问答只走目标/约束分派、独立子上下文、结构化交接和独立核验。演示保持无网络。旧快速 QA、查询规划、评测与审计移到 deepsearch_experiments，训练留在 search_policy；生产启动不加载离线包。

轨迹迁到仅标准库的 deepsearch_tracing。业务只依赖事件/记录协议；应用适配器转换安全模型诊断。成功、失败、未知分组保留，内部核验与人工正确性/根因标签分离；记录失败不阻断问答，导出不覆盖人工文件。

兼容边界：HTTP、有效 CLI、配置身份与用户数据格式保持；内部导入不保留广泛兼容层。只保留旧 TextChunk 类路径的最小反序列化别名，以及 ASGI、PDF、MCP、评测和审计 CLI 薄入口。显式关闭 Agent 的旧生产配置给出迁移错误。所有历史实验和 ADR 原结论保留，适用版本由历史索引说明。

取舍：继续使用本地 JSON/SQLite 与进程内线程，不新增服务、队列或通用仓储框架。抽出的接口限于实际跨模块边界；旧实验与新代码的实现指纹不同，必须使用新运行目录。版本化契约夹具、依赖审计和完整回归防止目录整理掩盖行为变化。
