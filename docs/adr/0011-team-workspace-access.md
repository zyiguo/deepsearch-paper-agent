# ADR-0011：可选团队身份与独立工作空间

状态：Accepted（2026-10-18）；补充 ADR-0006、0008 与 0010，默认单用户模式保持。

## 问题

单用户业务资源没有用户归属字段。只增加登录页面或在文献列表中筛选，无法覆盖原文文件、图像、会话记忆、Wiki、检查点和 Agent 工具的访问。当前仍为单 API 进程与内存索引，不适合直接声明共享数据库多租户能力。

## 决策

显式启用 `ACCESS_MODE=team`。统一身份库保存账号、过期会话、成员关系和独立安全审计；业务资源按服务器生成的工作空间 ID 放入独立目录。团队装配根在校验当前成员权限后，将 `/w/{workspace_id}/api/...` 分派到同一进程内按需装配的原业务运行环境，复用原路由与应用用例，不复制第二套检索或问答实现。

每个工作空间独立拥有索引/锁、SQLite 会话/运行/检查点、文献/附件、工作记忆、Wiki、可选轨迹与 Redis namespace。Windows 运行目录转换为扩展长度路径，避免嵌套附件文件名超过传统路径长度。未授权成员、系统管理员和非成员均不能通过其他入口读取业务资源；管理员只管理账号。所有者管理成员，editor 可读写，viewer 只读。当前不提供所有权转移、公开注册、匿名分享或工作空间删除。

采用随机盐 scrypt 密码摘要和随机 256-bit 不透明会话 Token。数据库仅存 Token 的 SHA256，Cookie 为 HttpOnly / SameSite=Strict，默认 Secure，固定有效期默认 8 小时。登录按连接来源与账号限频；重登录撤销该浏览器旧 Token，退出撤销当前 Token，修改/重置密码及停用账号撤销该账号所有会话。签发 Token 时在事务内再次检查密码摘要与停用状态，避免重置密码并发期间签发旧凭据会话。

所有写请求（含登录、上传和 SSE）要求明确请求头，并校验存在的 Origin，不信任代理传入的用户或工作空间头。账号 JSON 请求限制 8 KiB，校验失败不回显密码字段。响应禁止共享缓存。首次管理员通过本机密码提示 CLI 创建，无默认账号密码或网络自助提权入口。

浏览器请求和资源 URL 显式绑定空间；切换空间执行完整导航，不在共享服务端会话中存储“当前空间”，避免多个标签页互相改写目标。仅会话选择 ID 可按用户和空间存入本地存储，密码与 Token 不进入浏览器持久存储。

## 取舍与后续

相较逐表增加租户字段，这种隔离方式复用现有数据格式并减少漏过滤风险，代价是每个已打开空间拥有独立模型客户端、线程与内存索引。默认最多打开 8 个空间；达到容量返回 503，不驱逐仍有任务的空间。保留单进程部署约束，不能据此横向扩容。

成员撤销影响之后的请求；已接纳任务和已建立的文件/SSE 响应可能完成，已下载的内容不能收回。中断任务继续使用原恢复机制，没有新增持久队列。团队模式拒绝 MCP 客户端和服务端配置，直至其资源与传输也支持工作空间授权；本地模式的既有 MCP 能力保留。

旧本地文件不自动认领、迁移或合并。未来数据导入必须显式选定所有者并验证来源，不能把全局旧索引直接挂给全部成员。备份需包含身份库与业务目录；本轮不提供备份调度、多副本、计费配额、SSO、MFA 或完整线上安全验收。
