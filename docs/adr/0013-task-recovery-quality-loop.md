# ADR-0013：任务提交、离线还原与质量回归闭环

状态：Accepted，2026-10-18。补充 0010、0011、0012。

## 背景与决策

任务表、答案库、检查点和轨迹分别持久化。答案落库与任务状态不是一个跨存储事务，数据库停机、HTTP 断开或进程退出都可能留下未确认状态。单独保存数据库备份也不能恢复附件、索引及检查点。内部核验通过不能替代人工正确性标签。

继续采用单 API 模块化单体，不引入 Redis 队列、自动付费重试或分布式租约。普通和流式会话统一保存任务，按可选客户端幂等键去重；答案运行关联为最终事实，状态歧义通过查询已保存轮次修复。取消和进度用条件状态转换，恢复同时校验输入/语料、模型预算、技能与会话上下文，缺少检查点拒绝隐式重跑。

部署生命周期和维护写入口共用进程文件锁。停止应用写入后，打包 PostgreSQL schema 逻辑备份和完整业务文件，逐表与逐文件指纹封存；SQLite 模式打包原文件。还原工具只支持新目录和新隔离 PostgreSQL 容器，不提供覆盖现有数据库的快捷操作。还原后先核对全部表，再撤销登录会话，并用非 superuser 的真实业务存储读取验证。

质量流程在独立标准库轨迹包中完成：冻结轨迹、人工审核、错例根因、匹配条件回归、关联修复。保留执行分组、内部核验、人工正确性与根因四组信号。未知不进入正确率分母；候选缺评、身份不匹配或缺少修复引用时不能关闭错例。

## 取舍及边界

- 不新增 PostgreSQL 表结构版本，执行尝试/安全诊断与恢复身份放在已有 JSON 请求扩展字段中，旧数据继续可读；旧任务缺少身份时只能核对已提交答案，不能盲目续跑。
- 文件锁只约束本应用及维护入口；外部 SQL、其他文件工具和复制到不同根目录启动的进程仍须由操作者停写。不是分布式锁。
- 逻辑备份恢复粒度为显式备份时点，没有 WAL 连续归档或自动异地备份。本轮恢复工具优先支持当前本机 Docker PostgreSQL，远程库需要专用适配器。
- 备份包含用户内容与密码摘要，应按私有业务数据保管；模型/数据库连接密钥不打包，只记录配置摘要。复建部署需重新提供密钥、应用版本与运行依赖。
- 哈希用于检测意外损坏和记录版本关联，不提供抗管理员篡改签名。人工标签是具名操作者的显式输入，不是模型自动给自己的训练标签。
- 质量闭环不自动运行云模型；真实质量提升必须由匹配条件的新运行与人工复核证明，合成验收不能当作业务正确率。

操作入口与验证边界见 [运行保障说明](../RELIABILITY_RECOVERY_QUALITY.md)。
