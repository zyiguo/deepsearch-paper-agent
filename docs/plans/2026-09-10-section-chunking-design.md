# 论文规则分节与分块

用户已确认：先用纯文本标题规则识别章节，再按段落/句子分块，允许章节跨页并保留逐页原文映射。
本次不读取字体、书签或版面，不使用模型判断边界，不自动改写正文，不重建已有索引。

## 实现约定

- 新上传 PDF 使用 section-rules-v1：目标 600 字符，硬上限 900，完整单元重叠上限 120，短尾目标 120。
- 识别独立行标准中英文标题、数字层级标题和中文章/节标题；排除明显目录页码、图表标题、引用条目、公式和句末正文。
- 章节边界优先，不跨章节重叠；段落优先，长段落按句子拆分，超长句才硬切。
- 无可靠标题时按页进行段落/句子回退，不凭空推断章节。普通固定滑窗 helper 保留用于兼容。
- 片段正文保留原文；section_path、page_number（起始页）、page_end、page_spans 记录标题层级与逐页字符位置。
- page_spans 同时记录页内 start/end 和块内 chunk_start/chunk_end，均为 Python 字符偏移，左闭右开，不是 token 或 PDF 坐标。
- 标题路径附加在检索输入中，但不改写展示用原文；向量和 BM25 使用同一检索文本。
- 每块记录策略版本和参数。快照支持旧版读取；所有解析与验证完成才替换内存。
- 新引用保留范围、章节与逐页原文；前端可直接打开涉及的每页。旧历史只有单页时仍兼容。

## 验证与边界

行为测试覆盖标题层级、误判防护、跨页映射、章节隔离、完整句重叠、硬上限、回退、快照往返和入库/API。
这是软件功能验证，不进行真实问答质量评测或付费模型调用。
规则不能保证识别任意排版：双栏乱序、无换行标题、复杂列表、异常目录仍可能误判；后续可引入版面信息。
旧索引仍按原块检索；重复上传去重不会自动重分块。重建入口与迁移单独确认，避免隐式费用。
