# 论文图表与扫描页：按页多模态阅读

## 范围

第一版识别 PDF 的扫描文字、图、表和公式，按论文和页码检索、回答并核验。用户选择云端视觉模型，并要求模块解耦。原页是最终证据；OCR 和视觉描述用于检索，可能有识别错误。当前定位精度是页面，不提供图表框选、区域裁剪或数值自动计算。

## 模块与依赖

| 模块 | 职责 | 注入接口 |
| --- | --- | --- |
| `vision_config.py` | 独立视觉模型配置、限制及缓存身份 | `.env.vision` |
| `multimodal.py` | 页面分析结构、缓存、OCR 与视觉片段准备 | `PageAnalyzer`、页面图片回调 |
| `vision.py` | 云端视觉模型转成 `PageAnalysis` | `ImageLLMClient` |
| `visual_evidence.py` | 解析原页引用、控制图片数量和预算、视觉回答 | `ImageLLMClient`、来源/页码到图片的回调 |
| `image_embeddings.py` | 独立图像 Embedding 配置和云端适配 | `.env.image_embedding`、启动时注入的共享凭据 |
| `image_index.py` | 独立页面图像向量空间、ANN、范围过滤、RRF | 公共 `ImageEmbeddingClient` 协议 |
| `documents.py` | 保存原 PDF、后台调度、原子替换索引、图片渲染 | `DocumentProcessor` |
| `qa.py` / `research_graph.py` | 问答、研究调度与逐条核验 | `VisualEvidenceProvider` |
| `api.py` | 在启动时构造并连接上述依赖 | 配置与应用工厂参数 |

研究图不依赖文献库、具体视觉模型或图片文件路径。页面处理器不访问 FastAPI state、知识库或文献库。知识库协调文字索引和独立图像索引，不渲染图片或执行 OCR。图像索引依赖公共向量协议，不依赖具体云端适配器；文献库负责传入渲染好的图片。视觉问答 HTTP 调用复用现有客户端的超时和错误处理。

图片模型协议 `ImageLLMClient` 位于公共 `llm.py`；页面分析适配器与视觉问答服务各自依赖它，二者没有相互导入。

更换 OCR/版面分析工具时实现 `PageAnalyzer`；更换模型接口时实现 `ImageLLMClient`；更换图片存储时替换图片解析回调；这些变化不需要修改研究图。

## 导入流程

1. 保存原 PDF，后台提取已有文字。开启视觉功能时允许没有文字层的 PDF。
2. 按页渲染最高 3200 像素长边的原图，并通过页面分析器提取视觉内容。扫描页逐字 OCR；混合页面补充未提取的扫描区域文字。
3. 文字沿用章节分块，图、表、公式分别形成检索片段，保留类型及 `visual_pages`。同页正文也关联原图，避免只检索到图注时看不到图。
4. 对准备好的片段批量生成文本向量；启用图像 Embedding 时，各页原图另生成视觉向量，保留独立模型身份和向量空间。图像索引不要求 OCR 或描述存在。
5. 新片段和向量完整成功后，替换同一来源的旧索引并保存快照；失败不替换当前索引。逐页分析缓存保留，重试可复用成功页面。

缓存按 PDF 内容哈希、视觉接口地址、模型名和解析提示版本隔离。模型改变后重新分析。已有文字文献可通过 `POST /api/documents/{id}/analyze` 升级；同一来源替换，不重复添加。

## 回答与核验

检索在文献范围约束内分别运行 BM25/文本向量融合与图像向量检索，再以 RRF 合并两路排名，不直接合并不同向量空间的相似度。图像分支用同一视觉 Embedding 模型编码问题。含原图命中的候选通过视觉模型重排，候选页数受视觉预算约束，失败回退融合排序。命中视觉页后，Answerer 和 Verifier 各自读取这些原图，并明确告知 OCR/视觉描述可能有误。研究调度仍使用文字模型。未配置视觉模型、原图缺失、图片数量或预算超限时返回明确错误，不将描述默认为经过原图核验。

API 和会话历史附加 `evidence_kind` 与 `visual_pages`。旧片段默认 `text`，旧快照和旧会话可以读取。前端展示证据类型及页面缩略图，点击可打开原页。

原页解析回调只读取原 PDF 和文献元数据，不读取知识库，避免问答持有知识库锁时重复获取同一锁。

## 配置与成本

默认视觉阅读和图像检索均关闭。启用时每份新上传 PDF 按页发送图片到用户配置的视觉服务及图像 Embedding 服务；重排、问答和核验还会发送命中的页面。模块默认使用独立配置，只有显式共享标志才在启动时注入主模型或文字 Embedding 的凭据。页面缓存和图片保存在本地 `data/`，不加入 Git。旧文献可单独补建图像索引，不重新分析文字或图表。

PDF 限制沿用 10 MiB、100 页；原生或 OCR 正文上限 100000 字符，全部检索片段上限 300000 字符。默认单次最多 8 张图片，图片 Token 预算是可配置的保守估算，需要与服务商的图像计费规则匹配。

## 验证边界

离线测试覆盖：真实扫描 PDF 的本地解析和渲染、模拟视觉服务、缓存与模型身份、升级替换、失败保留旧索引、重试、原页附件、Answerer/Verifier 接口隔离、引用保存与重启兼容。

真实扫描文字识别精度、复杂表格与公式质量、图表数值识读仍需使用实际视觉模型和用户论文评测。软件契约通过不能表述为模型效果已验证。
