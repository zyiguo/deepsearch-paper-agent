# 父子通信轨迹实施计划

目标：为后续失真率评估保留可关联、可审计的观测数据，并区分成功、失败和未知。

1. 复用现有 RAGTraceRecorder/TraceStore，保持逐事件提交、哈希链和故障不阻断问答。
2. 新增请求局部事件作用域，跨异步任务和工具线程关联 task_id、父调用、研究轮次与业务运行。
3. 记录任务下发、子模型输入、工具接收内容、原始/校验后结果、本地证据快照、裁剪前后父输入和最终调度。
4. 持久化 run.classified，将运行完成与内部核验分开，成功/失败/未知分组不充当人工正确性或根因标签。
5. 新增只读查看及分组 JSONL 导出，保留未分派就失败的运行、未完成尝试和记录故障；避免覆盖既有导出。
6. 用离线真实应用图验证正常、拒绝、异常、中断、并发隔离与裁剪对比；再执行完整回归。附可直接运行的合成示例与文档。
