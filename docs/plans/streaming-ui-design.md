# 流式会话与简化界面

用户已确认：阶段实时推送，核验结束后输出答案，不显示未经核验草稿；移除技术介绍。

## 实施清单

- [ ] 后端：ResearchWorkflow、AnswerService 增加可选 on_progress(stage) 回调，不修改模型协议。
- [ ] 新增 POST /api/sessions/{id}/turns/stream，SSE 事件为 status、answer、done、error；保留旧接口。
- [ ] 后台线程沿用现有锁和会话保存逻辑。每 10 秒 heartbeat。先保存最终答案，再按段发送 answer，最后 done 携带完整已保存 turn。不加人工延时。
- [ ] 断线不自动重新提交；后台可能继续完成并保存，前端提示刷新会话核对。暂不提供取消推理按钮，不承诺断线停止计费。
- [ ] 前端 fetch ReadableStream 解析 SSE，处理 UTF-8 分片、错误、缺少 done、请求清理；显示实时阶段和最终引用。
- [ ] UI 删除技术名称、宣传标语、API 文档入口；高级检索/保存选项折叠。保留隐私计费与错误提示。
- [ ] 离线定向回归：事件顺序、错误脱敏、仅保存一次、解析分片、断线不重试。重测试和真实验收写入 Markdown。

不引入新依赖、不重建知识库、不提交用户改动。阶段流是实际推送；答案段在核验结束后发送，不是模型 token 流，也不是模拟打字。
