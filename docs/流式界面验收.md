# 流式问答与简化界面验收

## 已实现

- 新接口 `POST /api/sessions/{id}/turns/stream`，原同步接口保留。
- 真实阶段事件：等待、规划、检索、起草、核验、修订；等待期间有心跳保活。
- 最终回答保存成功后发送正文段与引用，最后用 done 确认完整记录。没有人工打字延时，也不展示未经核验的草稿。
- 前端接收 UTF-8 分片，显示当前处理阶段和等待秒数。发送期间禁用重复发送和会话切换，断线不自动重发。
- 移除技术介绍、检索算法说明、宣传标题及 API 文档入口。检索参数与存储操作默认折叠；保留费用/隐私提醒、错误提示和引用。

这是阶段流，不是模型逐 token 输出。最终各段可能很快一起显示，这是正常现象；真正实时更新的是模型处理阶段。

## 已完成的离线检查

后端定向回归 30 项通过，1 项涉及应用配置的 API 测试主动排除。包括：答案阻塞时先收到阶段事件、落库一次、异常脱敏、缺失会话 404、图流程与漏答修复。

前端定向测试 11 项通过，包含逐字节 UTF-8 拆包、缺少 done、错误事件和不自动重试；生产构建通过。这些不代表浏览器视觉与真实模型端到端已验收。

## 启动

在原后端终端 Ctrl+C 后执行：

```powershell
Set-Location '.'
& .\.venv\Scripts\python.exe -B -m uvicorn deepsearch_agent.api:app --host 127.0.0.1 --port 8000
```

前端已运行时刷新页面即可；未运行时另开终端：

```powershell
Set-Location frontend
& 'C:\Program Files\nodejs\node.exe' 'C:\Program Files\nodejs\node_modules\npm\bin\npm-cli.js' run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

打开 `http://127.0.0.1:5173/`。无需重新上传现有 PDF。

## 由你验收

1. 界面：不再有大幅宣传标题、BM25/RRF/Embedding 技术说明或 API 文档入口。文档、会话、提问、引用仍可操作。
2. 新建会话，发送一次原 AX-247 四属性问题（会产生真实模型费用）。问题立即出现在对话中，随后阶段状态实时变化；不是一直停留在统一的“等待回答”。
3. 最终检查四项事实及引用，刷新后只有一条问答，不重复保存。跨页原文按钮仍应正常打开。
4. 可选断线检查：断开浏览器网络后不能显示“已完成”，应提示核对会话，不自动重发。恢复网络后刷新会话确认是否已保存。
5. 小窗口和长历史：输入框、发送按钮、当前处理卡片可见，引用文字不横向撑破布局。

注意：关闭页面或断线不等于取消后端推理，后台可能继续处理、计费并保存。当前前端最多等待 10 分钟，超时先刷新核对；不要立刻重发。当前仍沿用知识库共享锁，生成时其他读取/写入操作可能需要等待。本次不改并发架构。

如进度不更新，记录停留阶段、浏览器错误以及是否已重启后端；不要为了验证连续发送多次。
