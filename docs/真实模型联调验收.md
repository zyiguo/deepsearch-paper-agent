## 5. 第三阶段：新文档入库与跨页引用（会产生费用）

测试样本已位于 `output/pdf/section-integration-fixture.pdf`，由 `examples/retrieval/build_integration_pdf.py` 生成，是两页合成文本，不是真实论文。请先本地打开确认两页可读；无需重新生成。

注意：上传正文会发送给配置的 embedding 服务；提问时检索片段会发送给模型服务。只用你允许发送的资料。当前不要假设存在按单个 PDF 隔离检索的功能；若知识库包含敏感文档，先停止真实验收，不要为了测试删除它们。

### A. 上传与分块

1. 在前端上传该 PDF，等待 ready。
2. 确认页数为 2。按当前规则预期识别 Abstract、Methods、Calibration、Results、Conclusion，约 5 个片段；若数量不同，记录实际值，检查文本抽取和分块原因，不直接判定正确。
3. Calibration 的句子从第 1 页结尾延伸到第 2 页开头，不能只保留半句。
4. 如提示文档已存在，说明可能命中了去重，不能算本次完成了新 embedding。记录情况，不删除原文档强行重试。

### B. 先只发一个问题

新建专用验收会话，提问：

> AX-247 的采样频率和实验 GPU 数量分别是多少？校准间隔及参考信号颜色是什么？

预期事实：100 Hz、两块 GPU、十二秒、白色。每项事实必须有对应证据，不能只看答案措辞相似。

验收：

- [ ]  无 502、超时、格式校验失败或截断提示。
- [ ]  四个事实都正确，且引用内容直接支持。
- [ ]  校准证据保留第 1–2 页范围，章节为 Methods 下的 Calibration。
- [ ]  引用中第 1 页和第 2 页都能打开原文。

如果首次请求失败就停止。一次问答可能触发多个角色及多次重排序调用，不要连续点击发送。超时后先刷新会话检查是否已保存，避免重复付费。

### C. 首问通过后再逐条执行

1. 追问：`它的校准间隔是多少秒？` → 十二秒，有正确引用。
2. 缺失信息：`AX-247 的制造商和售价分别是什么？` → 明确资料不足，不编造事实或引用。
3. 刷新浏览器 → 问答和引用保留。
4. 在原终端正常重启后端 → 会话、文档仍可读取。

这些是少量功能验收，不是评测基准，也不能证明图的所有修订、补查、停止分支均在真实模型下覆盖。
