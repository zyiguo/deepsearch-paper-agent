# 选定文献检索

## 使用

1. 重启后端以加载新的请求参数和范围过滤；前端刷新页面。
2. 左侧每篇已入库 PDF 前可以勾选。默认全选当前可用 PDF；“清空”后发送按钮禁用。未完成入库的文献不可选。
3. 仅勾选 `section-integration-fixture.pdf`，提问区应显示“仅检索已选 1 篇”。
4. 问一次原 AX-247 四属性问题。所有新引用必须来自这篇 PDF，不允许 example.pdf / demo:// 或其他未选文献。参考事实：100 Hz、两块 GPU、十二秒、白色。
5. 取消这篇、改选其他文献后，下一轮不应引用这篇 PDF。旧历史中的引用保留，不属于本轮检索结果。

选择作用于当前页面内后续问题，跨会话沿用，刷新页面默认重新全选；尚未把选择范围永久绑定到会话或写入历史。回答进行中不允许改选，搜索文献名称不会自动取消隐藏的已选项，已选数量始终显示实际范围。

## 后端约束

流式会话、普通会话和 /api/ask 均支持 `document_ids` 数组。真实检索模式下：

- 指定数组：仅接受索引内真实 pdf:// 文献的 ID。
- 空数组、未知 ID、未入库文献：返回 422，在模型调用前拒绝，不自动回退全库。
- 旧客户端未传字段：兼容为全部已索引真实 PDF；依旧排除 demo://。
- 独立演示模式不传范围时保留原行为，不能据此当作真实模式验收。

AnswerService 为本次请求创建候选集视图：所选 chunks 和对应 vectors 一起筛选，BM25 缓存独立重建。向量评分、BM25、RRF、重排序及补查都在这个视图中进行。原索引不修改，不重新生成文档向量，不删除演示数据或用户文件。

范围限制保证本轮检索证据来自所选文献，不保证模型答案语义一定正确。原会话历史仍可作为理解追问的上下文（不作为证据）；要避免旧回答干扰，可新建会话验收。本功能不是多用户权限隔离。

## 重启后端

先在原后端终端 Ctrl+C，再运行：

```powershell
Set-Location '.'
& .\.venv\Scripts\python.exe -B -m uvicorn deepsearch_agent.api:app --host 127.0.0.1 --port 8000
```

打开 `http://127.0.0.1:5173/`。无需重新上传 PDF。
